# The Reddening Map

An interactive atlas of the Anglo-Indian wars, 1686–1947: scrub the timeline and watch the
subcontinent change hands, treaty by treaty.

**Live:** https://sxhxmkxmxr.github.io/anglo-indian-wars/

`index.html` is the whole thing — a single self-contained file (map geometry, data and fonts
inlined). Download it and it works offline.
